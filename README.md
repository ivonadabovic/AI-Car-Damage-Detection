# TDC - AI Procjena oštećenja vozila

## Opis
Web aplikacija za automatsku procjenu oštećenja vozila korištenjem YOLO AI modela.

## Tehnologije
- HTML/CSS/JavaScript
- YOLO11m (ONNX)
- CarDD dataset

## Korištenje
1. Otvorite `index.html` u pretraživaču
2. Uploadujte fotografiju vozila
3. AI detektuje oštećenja i preporučuje uslugu
